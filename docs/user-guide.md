# 用户使用手册（第一阶段）

## 1. 全局界面与快捷导航

- **悬停弹出与回缩导航栏**：桌面端左侧导航栏默认收起为窄图标栏以最大化工作视野。将鼠标移动到左侧导航栏上即可自动弹出完整分组菜单；移开鼠标自动回缩。如需常驻展开，可点击导航栏顶部的「固定展开」图标按钮。
- **全局命令面板 (`Ctrl + K` / `⌘ + K`)**：在任意页面按下快捷键或点击顶栏搜索框，即可快速搜索并跳转到任一功能模块、直达权威外部网站或切换深浅色主题。
- **深色与浅色主题**：点击顶栏右上角太阳/月亮图标即可在深色（Dark）与浅色（Light）精密仪器主题间无缝切换，自动记住您的偏好。

## 2. 统一 AI 模型与本地客户端配置中心

点击顶栏右侧模型按钮（如 `OpenAI` / `Gemini`）打开配置抽屉：
1. 可选择默认推理供应商（OpenAI、Google Gemini 或兼容 OpenAI 协议的自定义端点）。
2. 若服务器管理员未预置全局密钥，您可填入个人 API Key（仅保存在您当前浏览器本地，不会明文上传存储）。
3. 点击「真实探测当前模型接口连通性」可即时验证 API Key 与模型名称是否可用。
4. 底部可手动探测本地是否已运行「基米大师」客户端桥接服务。

## 3. 常用网址导引 (`/hub`)

1. **搜索与筛选**：支持按名称、域名、介绍或标签实时搜索；支持按六大分类胶囊、「仅看收藏」与「仅官方源」组合筛选。
2. **星标收藏置顶**：点击任意网址卡片右上角的星标即可收藏，收藏网站会自动排在列表最前方，并保存在当前浏览器对应的服务端工作区记录中。
3. **自定义网址管理**：点击「添加自定义网址」可录入您常用的公开链接（仅限 `https://` 或 `http://` 安全协议），录入后支持随时编辑或删除。
4. **备份与迁移**：点击「导出自定义」可将个人添加的网址下载为标准 JSON 文件，更换设备或浏览器时通过「导入 JSON」一键恢复（自动跳过重复链接）。
