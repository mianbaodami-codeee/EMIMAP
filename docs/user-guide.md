# 用户使用手册（第一阶段 & 第二阶段）

## 1. 全局界面与快捷导航

- **浅色基底与双主题切换**：系统默认采用清爽高对比度的浅色精密仪器基底（Light），点击顶栏右上角太阳/月亮图标可在浅色与深色（Dark）主题间无缝切换，自动记住您的偏好。
- **悬停弹出与回缩导航栏**：桌面端左侧导航栏默认收起为窄图标栏以最大化工作视野。将鼠标移动到左侧导航栏上即可自动弹出完整分组菜单；移开鼠标自动回缩。如需常驻展开，可点击导航栏顶部的「固定展开」图标按钮。
- **全局命令面板 (`Ctrl + K` / `⌘ + K`)**：在任意页面按下快捷键或点击顶栏搜索框，即可快速搜索并跳转到任一功能模块、直达带有品牌渐变图标的权威网站或切换主题。

## 2. 统一 AI 模型与本地客户端配置中心

点击顶栏右侧模型按钮（如 `OpenAI` / `Gemini`）或左侧导航栏底部的配置图标打开设置抽屉（支持 `Tab` / `Shift + Tab` 抽屉内键盘焦点循环与 `Esc` 关闭并回到原入口）：
1. 可选择默认推理供应商（OpenAI、Google Gemini 或兼容 OpenAI 协议的自定义端点），此配置同时驱动「全球地图 AI 空间问答」与「AI 资源寻找代理」。
2. **密钥与网络请求安全边界**：携带 API Key 的上游请求强制使用 `https://` 协议、禁止自动跟随 HTTP 重定向，并校验域名解析的全部 IP 均为公网单播地址；服务器预置密钥仅允许发往管理员配置的可信端点，自定义 Base URL 或「兼容端点」强制仅使用本地填写的个人 API Key（BYOK）。
3. **服务端点连通性检查（三态模型核验）**：点击「服务端点连通性检查」后，模型结果明确区分为 **已确认**、**未找到（404）** 与 **无法确认**。

## 3. 常用网址导引 (`/hub`)

1. **品牌渐变图标与搜索筛选**：预置 24+ 权威游戏、开源、AI 与官方文档网站，每个跳转方块内置对应品牌矢量标识与定制渐变底色；支持实时搜索、六大分类胶囊、「仅看收藏」与「仅官方源」组合筛选。
2. **星标收藏置顶与自定义书签**：支持一键星标收藏、录入/编辑/删除个人自定义网址，以及 JSON 格式备份导出与去重导入。

## 4. 全球地图与 AI 空间分析 (`/map`)

1. **交互式全球地图与坐标定位**：支持鼠标拖拽缩放、点击任意位置拾取经纬度、关键词搜索城市/地标、快捷节点直达及精确经纬度跳转。
2. **地点收藏、多点对比与历史记录**：可将选中地点（含工程备注）持久化收藏到数据库；点击「加入多点对比」可并列计算多个城市之间的球面大圆距离（Haversine km）；所有问答自动保存在「查询历史」标签页。
3. **三源隔离 AI 空间问答**：输入自然语言问题后，系统将结果严格拆分为 **实测地理要素**、**联网检索信源** 与 **AI 推理结论** 三个可溯源区块；未配置 API Key 时仍可正常获取实测坐标与公开背景信源。
4. **结果导出**：支持一键导出标准 RFC 7946 `.geojson` 空间要素文件或 `.md` 分析报告。

## 5. AI 自主资源寻找代理 (`/discover`)

1. **四步透明检索链路**：输入想寻找的正版游戏、开源项目、开发工具或技术文档后，界面实时展示「需求拆解 → 多源检索 → 官方域名核验 → 选型综述」完整步骤与耗时。
2. **可验证结构化卡片**：每条结果均标明资源名称、来源域名、版本/更新时间、授权与定价、**是否官方源**、**可信度核验依据** 与 **安全注意事项**，支持按资源类型或「仅看官方源」过滤，并支持多轮追问及导出 Markdown / JSON。
3. **正版与安全合规准则**：系统严禁检索盗版破解、注册机或绕过付费/授权门禁的内容，遇到违规请求将主动拦截并引导使用正版或开源替代方案。

## 管理账号与地图底图

完整服务通过 `/login` 登录，唯一管理账号为 `Admin`。部署者在服务器设置至少 16 字符的随机 `ADMIN_PASSWORD` 后重启服务。密码留空时关闭管理登录，无默认密码。管理接口与页面逐次验证服务端会话；退出、密码轮换或八小时超时会使会话失效。多实例部署请配置共享 Redis。个人模型设置及个人地点收藏仍属于各访客的工作区。

世界地图首先显示随应用发布的 Natural Earth 国界与海岸线；WebGL 就绪后切换至含比例尺的 1:50m 交互底图。点击「街道视角」可放大至选中位置并请求 OpenStreetMap 瓦片。无法使用 WebGL 时仍可拖动、缩放矢量底图并选择坐标。坐标以 WGS84 显示，可直接复制。审阅版可离线查找内置地点，完整联网分析需运行后端。

底图数据取自 [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/)，采用公有领域数据。品牌轮廓部分取自 [Simple Icons 11.15](https://github.com/simple-icons/simple-icons/tree/11.15.0)，品牌标识归各权利人所有。

## Windows 测试与基米大师

在 `/windows-bench` 选择单项测试或运行全部。CPU 和内存测试在 Worker 中执行，图形使用 WebGL2，存储写入来源私有文件系统。设备信息由浏览器提供，物理硬盘型号与精确硬件配置由客户端读取。测试结果保存在此浏览器，可勾选两项同类成绩比较。

`运行榜单测试` 会取回一次性负载。选择 `发布本次成绩` 后，服务器复算负载并用数据库主键阻止挑战重放。浏览器上报的用时、系统和线程数属于参考数据。预览站点需要完整后端才能发布榜单。

`/jimi-master` 提供 Windows x64 测试 ZIP、.NET 8 桌面运行时链接和 SHA-256。操作说明和构建命令见 [客户端文档](../apps/jimi-desktop/README.md)。
